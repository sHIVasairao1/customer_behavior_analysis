# 📊 Data Analytics Project – End-to-End Analysis
An end-to-end data analytics project exploring customer purchasing
patterns, product preferences, discounts, subscriptions, and customer
segments. The project uses Python for data preparation and exploratory
data analysis (EDA), PostgreSQL for business-focused SQL analysis, and
Power BI for interactive visualisation.
Overview
A retail business wants to better understand customer shopping behaviour
to improve sales, customer satisfaction, and long-term loyalty.

Business question: How can the company use shopping data to identify
trends, improve customer engagement, and optimise marketing and product
strategies?

This project analyses customer transaction records to examine spending
patterns, product categories, customer segments, subscription behaviour,
discounts, reviews, and shipping preferences.

# Dataset
- Records: 3,900
- Columns: 18 in the original dataset
- Target of analysis: Customer demographics, purchase details, and
  shopping behaviour
- Missing data: 37 missing values in Review Rating
  
The dataset includes:
- Customer demographics: age, gender, location, subscription
  status
- Purchase details: item purchased, category, purchase amount,
  season, size, and colour
- Shopping behaviour: review rating, shipping type, discount
  applied, promo code used, previous purchases, payment method, and
  purchase frequency

# 4. Project Workflow

# Step 1: Data Loading

Imported the dataset into Python using Pandas.

Inspected the dataset structure, dimensions, and data types.

Reviewed initial records to understand the data.

# Step 2: Exploratory Data Analysis (EDA)

Generated descriptive statistics.

Identified patterns, distributions, and trends.

Explored relationships between variables.

Created visualizations to understand the dataset.

# Step 3: Data Cleaning & Preprocessing

Handled missing and duplicate values.

Corrected inconsistent data formats.

Converted columns into appropriate data types.

Prepared the cleaned dataset for further analysis.

# Step 4: SQL Analysis

Imported the cleaned dataset into a relational database.

Created and managed database tables.

Performed SQL queries to extract meaningful insights.

Used filtering, aggregation, joins, subqueries, and other SQL techniques.

# Step 5: Power BI Dashboard

Connected the database or cleaned dataset to Power BI.

Developed interactive visualizations.

Created KPIs, charts, and summary metrics.

Designed a dashboard to communicate key findings.
